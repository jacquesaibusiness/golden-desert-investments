# Dubai Skyline Video Placement

## Video Requirements
- **Format:** MP4
- **Filename:** `dubai-skyline.mp4` 
- **Resolution:** 1920x1080 (Full HD) minimum, 4K preferred
- **Length:** 10-60 seconds (will loop)
- **Size:** Under 50MB for web optimization
- **Content:** Dubai skyline aerial/cinematic footage

## Sources (Free/Royalty-Free)
1. **Pixabay** — pixabay.com/videos → search "dubai skyline"
2. **Pexels** — pexels.com/videos → search "dubai skyline"  
3. **Unsplash** — unsplash.com/s/videos/dubai-skyline

## Usage
Video will auto-play (muted) as background on homepage hero section.
Fallback to static image if video fails to load.
